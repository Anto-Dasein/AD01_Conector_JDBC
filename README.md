Práctica AD01 - Conector JDBC (Gestión de Inventario y Pedidos)


## Estructura del Proyecto

- config/: Clase ConexionDB para gestionar la conexión JDBC.
- dao/: Interfases e implementaciones de ProductoDAO y PedidoDAO.
- entities/: Modelos de datos Producto y Pedido anotados con Lombok.
- com.tiendadb.Main: Menú interactivo de consola.
