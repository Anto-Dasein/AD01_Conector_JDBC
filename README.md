Práctica AD01 - Conector JDBC (Gestión de Inventario y Pedidos)


## Estructura del Proyecto

- config/: Clase ConexionDB para gestionar la conexión JDBC.
- dao/: Interfaces e implementaciones de ProductoDAO y PedidoDAO.
- entities/: Modelos de datos Producto y Pedido con Lombok.
- com.tiendadb.Main: Menú de usuario
